[u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163):
one razor-sharp line, at most 200 characters, that is the funniest excuse
for skipping a pointless work meeting or Zoom call.

The entry:

> Sorry, I can't join — I'm already stuck in another meeting about whether this meeting should exist, and so far the verdict is no.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This validates the line against the competition gate (1–200 characters,
single line, not only whitespace, no leading/trailing spaces, valid UTF-8)
and writes it to `entry.txt` in the output directory.
